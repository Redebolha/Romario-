Recomendações de Rebalanceamento

Melhores Práticas para Rebalanceamento

🎯 Estratégia 25/25/25/25
  1. Distribuição Equilibrada: Cada classe deve ter 25% da carteira total
  2. Revisão Trimestral: Verifique o balanceamento a cada 3 meses
  3. Desvio Aceitável: Tolere até 5% de desvio antes de rebalancear
  4. Rebalanceamento Suave: Não faça mudanças abruptas, ajuste gradualmente
  5. Aporte Inteligente: Direcione novos aportes para as classes abaixo
💰 Distribuição por Objetivo
  1. Ações (25%): Crescimento de longo prazo, maior volatilidade
  2. FII (25%): Renda recorrente, renda fixa imobiliária
  3. Dólar (25%): Proteção cambial, diversificação internacional
  4. Emergência (25%): Liquidez imediata, proteção contra crises
📊 Quando Rebalancear
  1. Quando uma classe cai abaixo de 20% do total
  2. Quando uma classe ultrapassa 30% do total
  3. Após grandes mudanças de mercado
  4. Com cada novo aporte significativo
  5. No final de cada trimestre para revisão
